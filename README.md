# AutonBDA-Bench

An open benchmark for autonomous data science: tasks spanning **all six CRISP-DM
phases**, with expert-authored answers for the two expert-dependent phases (business
understanding, data understanding).

## Plan

| Release | Domain | Target |
|---|---|---|
| Design document v0.1 (draft) | — | 2026 |
| v1 | robotics — 50 tasks | FY2028 |
| v2 | bioinformatics — 50 tasks | FY2030 |

An annual open evaluation round invites any group to report on the same scale.

## Status — 2026-08-27

Design in preparation. No benchmark data has been released yet.
